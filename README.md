# JARVIS

Assistente pessoal, de uso particular. Este repositório contém apenas código: senhas, chaves e dados pessoais nunca ficam aqui.

Situação atual: etapa 1 (acesso com senha, banco de dados e núcleo animado).

Para testar fora da Cloudflare, com Node 22: `JARVIS_SENHA=sua-senha-longa npm run local` e `npm test`.
